# ex-tools-1

This is a simple one-page website project displaying my name and photo.

## Live Site

You can view the live website hosted on Netlify here:  
[https://iridescent-zuccutto-5c4745.netlify.app/](https://iridescent-zuccutto-5c4745.netlify.app/)

## Project Structure

- `index.html` — The main webpage displaying my name and photo.
- `your_photo.jpg` — The photo displayed on the webpage.

## Set Up

1. Created the `index.html` file with minimal HTML to show my name and photo.
2. Uploaded this project folder (`ex-tools-1`) to my GitHub repository `bootcamp`.
3. Connected the repository (or this specific folder) to Netlify.
4. Deployed the site on Netlify with its free static hosting service.
5. The site is automatically published with HTTPS and a public URL.
